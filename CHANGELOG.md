## Part 2 - CSS Styling and Responsive Design

### Date
2026

## Overview

Part 2 focused on improving the visual design, layout, responsiveness and usability of the Muramba PTY (LTD) website based on the requirements of the second part of the assignment.

---

## Changes Made

### 1. External CSS Stylesheet

- Used an external stylesheet located at `css/style.css`.
- Applied consistent styling across all website pages.
- Added reusable CSS classes for buttons, containers, sections, cards and layouts.

### 2. CSS Reset and Base Styling

- Added a CSS reset to provide more consistent styling across browsers.
- Added global box-sizing rules.
- Improved default margins and spacing.
- Added consistent base typography and page styling.

### 3. Typography

- Improved heading and paragraph styling.
- Added responsive typography using CSS `clamp()`.
- Improved font sizes, line heights and text spacing.
- Created clearer visual hierarchy between headings, subheadings and body content.

### 4. Layout Improvements

- Improved the overall page structure.
- Used CSS Flexbox for navigation, headers, footers and flexible content layouts.
- Used CSS Grid for gallery and card-based layouts.
- Improved spacing and alignment across the website.

### 5. Visual Styling

- Added consistent colour variables.
- Improved buttons and call-to-action sections.
- Added borders and rounded corners.
- Added box shadows for selected content areas.
- Added hover states for interactive elements.
- Added keyboard focus states.
- Added active navigation states.

### 6. Responsive Design

Responsive layouts were added for:

- Desktop
- Tablet
- Mobile
- Small mobile screens

The responsive design adjusts:

- Navigation
- Typography
- Images
- Service sections
- Gallery layout
- Forms
- Buttons
- Footer
- Map
- Page spacing

### 7. Responsive Images

Responsive image techniques were implemented using:

- `srcset`
- `sizes`
- `loading="lazy"`
- `decoding="async"`

Additional responsive image versions were created for selected website images.

### 8. Accessibility Improvements

The website was improved with:

- Skip-to-content links
- Semantic main content areas
- Keyboard focus indicators
- Active navigation states
- Descriptive image alternative text
- Reduced-motion support

### 9. Page Improvements

The following pages were updated:

- `index.html`
- `about.html`
- `services.html`
- `gallery.html`
- `enquiry.html`
- `contact.html`

Each page was updated to use the improved visual design and responsive CSS structure.
